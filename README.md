# Controlador de Datas

Projeto desenvolvido como atividade PEX do curso de **Análise e Desenvolvimento de Sistemas**, com o objetivo de desenvolver uma aplicação web para cadastro e gerenciamento de produtos e suas respectivas datas.

## Funcionalidades

* Cadastro de produtos;
* Consulta de produtos cadastrados;
* Edição de registros;
* Exclusão de registros;
* Armazenamento dos dados em banco PostgreSQL.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Supabase
* PostgreSQL
* GitHub Pages

## Objetivo

Aplicar na prática conceitos de desenvolvimento web, operações CRUD, integração com banco de dados e versionamento de código utilizando Git e GitHub.
